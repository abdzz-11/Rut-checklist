RUT Checklist — تثبيت على الآيفون (يشتغل بدون إنترنت)
=====================================================

الملفات (لازم تنرفع كلها مع بعض في نفس المجلد):
  index.html, manifest.webmanifest, sw.js,
  icon-192.png, icon-512.png, apple-touch-icon.png

الطريقة المجانية: GitHub Pages
1) سوّ حساب على github.com (إذا ما عندك).
2) اضغط "+" ثم "New repository"، سمّه مثلاً: rut-checklist ، خلّه Public، ثم Create.
3) اضغط "uploading an existing file" واسحب الملفات الستة كلها، ثم "Commit changes".
4) ادخل Settings ← Pages ← تحت Branch اختر main و /(root) ← Save.
5) بعد دقيقة أو دقيقتين يطلع لك رابط مثل:
   https://YOUR-NAME.github.io/rut-checklist/

على الآيفون:
6) افتح الرابط في Safari (لازم Safari).
7) زر المشاركة ← "Add to Home Screen" ← Add.
8) افتح التطبيق من الأيقونة مرة وأنت متصل بالإنترنت، بعدها يشتغل أوفلاين.

تحديث التطبيق لاحقاً:
- ارفع index.html الجديد مكان القديم، وغيّر في sw.js السطر
  const VERSION = "rut-v1";  إلى  "rut-v2"  (وهكذا كل مرة)،
  ثم افتح التطبيق مرتين وأنت متصل عشان ياخذ النسخة الجديدة.

ملاحظات:
- التأشيرات محفوظة على الجهاز نفسه فقط.
- إذا مسحت التطبيق أو بيانات Safari تنمسح التأشيرات.
- المرجع: TSV 10-4008 R02 — راجع النسخة المعتمدة قبل الاستخدام الفعلي.
- الرابط Public، يعني أي أحد عنده الرابط يقدر يفتحه. إذا هذا مشكلة لسياسة الشركة،
  استخدم بديل خاص (مثل Netlify Drop مع كلمة سر بخطة مدفوعة) أو اسأل قسم الـ IT.
